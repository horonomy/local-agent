# Upstream (historical, not Local Agent behavior)

Local Agent is derived from ZeroClaw. Everything under this section is inherited upstream documentation, kept as historical record with its attribution intact. It describes the standard ZeroClaw build and refers to upstream installers, commands, links and decisions.

It is not a description of Local Agent. In particular, the pages grouped under "Inherited listener-surface pages" document features the `local-agent-minimal` profile excludes (channels, gateway, daemon and service listeners, relay, tunnels, embedded web, voice). They are not offered, supported or promised, and are listed only so that links from other inherited pages keep resolving. See [what is excluded](../setup/local-agent-minimal.md#what-is-excluded).

The upstream Architecture Decision Records live here unchanged. Provenance, the pinned baseline and the divergence ledger are in `UPSTREAM.md` at the repository root.
